# Handoff

Questo file non è più aggiornato a ogni sessione.

Il repo contiene due percorsi separati, ognuno con il proprio status e le proprie sessioni.

- **C++ (refactoring del driver)**: lo storico discorsivo vive in **`sessioni/`**, un file per sessione, nome = timestamp UTC. A inizio sessione: leggere `status-cpp.md` e **il file più recente** in `sessioni/`.
- **Reverse engineering**: tutto vive in **`reverse-engineering/`**. A inizio sessione: leggere `reverse-engineering/status-re.md` e **il file più recente** in `reverse-engineering/sessioni/`.
